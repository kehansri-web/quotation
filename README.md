# ⚡ QuoteCraft Pro - 10-Page Solar Quotation & Proposal Generator

A high-performance solar quotation generator with satellite rooftop mapping, locked company bank details, multi-page PDF generation, and central cloud database sync.

---

## 🚀 Instant Deployment on GitHub Pages

1. Push this repository to GitHub:
   ```bash
   git add .
   git commit -m "Deploy QuoteCraft Pro"
   git push origin main
   ```
2. In your GitHub repository:
   - Go to **Settings** → **Pages**
   - Under **Build and deployment** → **Source**, select **GitHub Actions**
3. Your app will be live at: `https://<your-username>.github.io/<repo-name>/`

1. Create a free account at [Supabase.com](https://supabase.com) (Free 50,000 rows / 1GB).
2. Create a new project and go to the **SQL Editor**.
3. Paste and run this SQL script:

```sql
alter table quotes add column if not exists sales_username text default 'SALES';
alter table quotes add column if not exists installer_brand text default 'kehansri';

create table if not exists company_config (

);

alter table company_config add column if not exists bank_label text default 'KehanSri Solar (Primary)';
alter table company_config add column if not exists bank2_label text default 'K Energy Solutions (2nd Company)';

alter table quotes enable row level security;

alter table users enable row level security;

create policy "Allow all access to quotes" on quotes for all using (true) with check (true);
create policy "Allow all access to config" on company_config for all using (true) with check (true);

```

## 📧 Automated Daily 08:00 PM IST Excel Email Report

QuoteCraft Pro automatically generates a multi-sheet Excel spreadsheet (`.xlsx`) and emails it to you every evening at **08:00 PM IST (14:30 UTC)**.

### 📊 Excel Workbook Structure:
- **Sheet 1: 📊 Executive KPI Dashboard** (Total Quotes, Total Quoted Capacity in kW & MW, Gross Pipeline Value, Net Client Outlay, Residential vs C&I breakdown, System Type distribution, Solar OEM Brand distribution).
- **Sheet 2: 📋 Quotations Detailed Ledger** (Quote Number, Date/Time, Customer Name, Phone, Address, Category, System Type, Capacity kW, Brand, Structure, Total Cost, Subsidy/AD Tax Shield, Net Outlay, 1st Year Savings, Sales Rep).
- **Sheet 3: 🏆 Sales Leaderboard** (Staff rankings, Proposals count, Total kW, Total Pipeline Value).

### ⚙️ How to Enable Email Dispatch in GitHub:
1. In your GitHub repository, go to **Settings** → **Secrets and variables** → **Actions**.
2. Click **New repository secret** and add the following:

| Secret Name | Example Value | Description |
| :--- | :--- | :--- |
| `REPORT_RECIPIENT_EMAIL` | `youremail@gmail.com` | Recipient email(s) for daily reports (comma-separated for multiple) |
| `SMTP_USER` | `sender@gmail.com` | Your Gmail address or SMTP email account |
| `SMTP_PASS` | `abcd efgh ijkl mnop` | Gmail 16-character App Password (or SMTP Password) |
| `SUPABASE_URL` | `https://xxxx.supabase.co` | Supabase Cloud Database URL |
| `SUPABASE_KEY` | `eyJhbGciOi...` | Supabase Service / Anon API Key |

3. The report will trigger automatically every day at **08:00 PM IST**. You can also run it on demand anytime under the **Actions** tab by clicking **Run workflow**!
